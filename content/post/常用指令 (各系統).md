
### 屬性清除
windows
```
attrib -r -h -s "資料夾路徑\*.*" /S /D

# 清除檔案權限
icacls "D:\EVENT 說明" /reset /T /C
# 檔案取得Everyone
icacls "C:\Users\gss\Desktop\PDM" /grant "Everyone:(OI)(CI)F" /T /C
```

macos
```
# 先清除隔離屬性
xattr -dr com.apple.quarantine "/資料夾路徑"

# 順便清除所有擴充屬性(保險起見)
xattr -cr "/資料夾路徑"

# 清除可能的 ACL
chmod -N "/資料夾路徑"

# 清除鎖定旗標
chflags -R nouchg "/資料夾路徑"
```
