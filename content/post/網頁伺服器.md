## Nginx 設定反向代理

設定位置：ls -la /etc/nginx/conf.d/
檢查重啟 sudo nginx -t && sudo systemctl reload nginx

## 設定檔寫法
```
/var/www/illumio-note/
/var/www/colortokens-note/

/etc/nginx/conf.d/

```


```
server {
    listen 80;
    listen [::]:80;

    server_name illumio-training.bd1.dev 172.16.8.90;

    root /var/www/illumio-notes;
    index index.html;

    charset utf-8;

    location = /illumio {
        return 301 /illumio/;
    }

    location ^~ /illumio/ {
        alias /var/www/illumio-notes/;
        index index.html;
    }

    location / {
        try_files $uri $uri/ =404;
    }

    access_log /var/log/nginx/illumio-notes-access.log;
    error_log /var/log/nginx/illumio-notes-error.log;
}
```
