## 1. 建立 GitHub Repository

在 GitHub 建立一個 repository：
- 一般專案網站：名稱可自訂，例如 `my-hugo-site`
    - 網址會是 `https://你的帳號.github.io/my-hugo-site/`
- 個人首頁：repository 必須命名為 `你的帳號.github.io`
    - 網址會是 `https://你的帳號.github.io/`
## 2. 把 Hugo 專案推送到 GitHub
在 Hugo 專案根目錄執行：
```
git init
git add .
git commit -m "Initial Hugo site"
git branch -M main
git remote add origin https://github.com/你的帳號/你的Repository.git
git push -u origin main
```

建議在 `.gitignore` 加入：
```
public/
resources/_gen/
.hugo_build.lock
```

`public` 不需要上傳；GitHub Actions 會自動產生它。
排除不關聯檔案
```
git rm -r --cached .
git add .
git status
git commit -m "Apply gitignore"
git push
```

## 3. 開啟 GitHub Pages

進入 GitHub repository：
1. 點選 **Settings**
2. 左側選擇 **Pages**
3. 在 **Build and deployment**
4. 將 **Source** 設為 **GitHub Actions**
GitHub 官方也採用這個方式發布 Hugo 網站。[Hugo 官方部署說明](https://gohugo.io/host-and-deploy/host-on-github-pages/)

## 4. 加入 Hugo 工作流程

在 repository 的 **Actions** 頁面搜尋或選擇 **Hugo** 範本，按下 **Configure**，儲存為：
```
.github/workflows/hugo.yaml
```

官方範本會完成以下工作：
1. 下載 Hugo
2. 執行 Hugo 建置
3. 上傳 `public` 目錄
4. 發布到 GitHub Pages
也可以直接採用 [Hugo 官方提供的完整 hugo.yaml](https://gohugo.io/host-and-deploy/host-on-github-pages/)。
如果主題是以 Git submodule 安裝，確認工作流程的 checkout 設定包含：
```
with:
  submodules: recursive
  fetch-depth: 0
```

## 5. 等候發布

提交工作流程後，到 GitHub 的 **Actions** 頁面查看進度。綠色勾勾表示成功；網站通常會在一兩分鐘內出現。
以一般 repository `my-hugo-site` 為例：
```
https://你的帳號.github.io/my-hugo-site/
```
以 `你的帳號.github.io` repository 為例：
```
https://你的帳號.github.io/
```
之後更新網站只需：
```
git add .
git commit -m "Update website"
git push
```

GitHub 就會自動重新發布。
常見問題：
- 樣式或圖片消失：通常是 `baseURL` 或絕對路徑問題；官方 Actions 範本會自動傳入 Pages 網址。
- 主題不存在：主題可能是 submodule，但沒有一起 checkout。
- 草稿沒有顯示：文章 front matter 中可能有 `draft: true`。
- 免費 GitHub 帳號：repository 通常需設為公開，才能免費使用 Pages
