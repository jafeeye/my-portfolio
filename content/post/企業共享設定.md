## WebDAV
Win 預設WebClient 服務僅支援 https 協議，而本地搭建的 webdav 服務和連結都是基於 http 協議的，因此造成了掛載失敗的情況，若要支援http需修改註冊表
`reg add "HKLM\SYSTEM\CurrentControlSet\Services\WebClient\Parameters" /v BasicAuthLevel /t REG_DWORD /d 2 /f`

> 以webdav協議不用webdav:// 只要打上https://即可

## SMB

這是如果你電腦沒有設定密碼(空密碼)情況可以下以下  
net use z: \\IP-ADDRESS\share-folder /user:username \login
有密碼:  
net use X: \\server\share /user:user abc  
你們也可以這樣下，沒有login，他會跳出來要你打帳號密碼。沒密碼就按enter鍵如下  
net use z: \\IP-ADDRESS\share-folder  
如果要清掉或取消連線可以用 \delete 如下:  
net use z: /delete  
列出所有網路磁碟: net use  
可以不用指定drive letter，用* 當做temp如下:  
net use * "\\server\my media" /persistent:no  

## Linux 共享SMB
1. 在在本機安全性原則/網路清單管理原則，點擊修改的網路連線，改成網路類型：私人
![](Pasted%20image%2020260621115753.png)

2. `etc/samba/smb.conf`
```
[Global]
workgroup = WORKGROUP//讓Ubuntu和Win兩台區網電腦同一網域
client min protocol = SMB3
client max protocol = SMB3
```



## CUPS

1. 創建CT 容器
```
apt update
apt install -y cups cups-client \
  printer-driver-foo2zjs usbutils
systemctl enable --now cups
cups-config --version
```
2. 在UI設定印表機直通，`pct set 105 --dev0 path=/dev/usb/lp0,uid=0,gid=7,mode=0660`
![504](static/Pasted%20image%2020261011203317.png)

3. 因為預設下載驅動也有問題，把Github下載驅動放到正確位置
```
cd /tmp

curl -fL --connect-timeout 10 --max-time 60 \
  -o sihpP1005.img \
  https://raw.githubusercontent.com/faradayfury/printer-all/main/foo2zjs/sihpP1005.img
  
mkdir -p /usr/lib/firmware/hp

/usr/bin/arm2hpdl /tmp/sihpP1005.img \
  > /usr/lib/firmware/hp/sihpP1005.dl
```

4. 載入驅動
```
## 手動輸入讓驅動正常載入
cat /lib/firmware/hp/sihpP1005.dl > /dev/usb/lp0
lp -d P1005 /etc/hostname
```
編輯開機自動載入驅動 
```
nano /etc/systemd/system/p1005-firmware.service

[Unit]
Description=Load HP LaserJet P1005 Firmware
Before=cups.service

[Service]
Type=oneshot
ExecStart=/bin/sh -c 'cat /lib/firmware/hp/sihpP1005.dl > /dev/usb/lp0'

[Install]
WantedBy=multi-user.target
```
編輯自動開機服務
```
systemctl edit cups.service

[Unit]
Requires=p1005-firmware.service
After=p1005-firmware.service

## 重新啟動
systemctl daemon-reload
systemctl enable p1005-firmware.service
```

HP P1005特性是:你必須先把 HP LaserJet P1005 關機再開機，Firmware 才能重新成功載入；如果只重新啟動 LXC，而印表機保持開機，重新傳送 Firmware 就會卡住。
