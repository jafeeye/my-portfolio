### 記譜格式：ABC
EasyABC、abc2svg支援簡譜、xml2abc
```
X:1                  % 樂曲編號為 1
T:Stille Nacht       % 樂曲標題：《Stille Nacht》（平安夜）
M:4/4                % 節拍：4/4 拍
L:1/8                % 每個音符預設為八分音符
Q:1/8=80             % 速度設定：每個八分音符 80 BPM
K:Bb                 % 調性：降 B 大調

%%score 1 2          % 定義總譜，包含聲部 1（簡譜）與聲部 2（五線譜）

V:1                  % 聲部 1：簡譜顯示
%%jianpu 1           % 啟用簡譜顯示模式（Jianpu）
%%MIDI control 7 0   % MIDI 音量設為 0，這個聲部不發聲（靜音）

V:2                  % 聲部 2：五線譜顯示
%%MIDI program 74    % 使用 MIDI 音色 74（直笛，recorder）

V:1,2                % 以下旋律同時寫入聲部 1 和聲部 2（簡譜和五線譜）
F>GFD3|F>GFD3|c2cA3|B2BF3|               

V:2                  % 接下來只對聲部 2（五線譜）寫入歌詞
w:Stil--le Nacht . . . .||  % 歌詞：《Stille Nacht》的開頭

```

### Capella

**辨識導入MuseScore**：Finale先打開後再轉換一次mxl輸出，轉換後打開正常(Audio2Score 匯出mxl、muiscxml 直接使用MuseScore開啟和弦字會跑版先用)
**辨識導入GuitarPro**：Audio2Score 匯出mxl， 直接使用Sibelius轉成未壓縮musicxml，再從GuitarPro開啟

### Finale

- MIDI 79 替換為 Hihat Open Hihat Close
- MIDI 72 替換為 S.D
- MIDI 65 替換為Kick

### EOP 簡譜大師

- 目前的新版本會出現會員功能，不要使用
- 可用來快速轉換不同調性
- 功能設定
- 製作簡譜團譜可以先輸出PDF，圓角和弦再丟進AI處理
- Ctrl++/-  
- CIDFont+F3 為EOP Number
- CIDFont+F4 為EOP Score
- CIDFont+F5 段落小節數字
- CIDFont+F6 和弦字體
- Shift +↑/↓ 整小節音符升高八度/低八度
- shift+# 升記號
- Ctrl+←/→ 向前移動小節
- Q/W/E/R/A/S/D 全/2/4/8/16/32/64
- 增加連音線 `T
- 切換輸入編輯模式 `SPACE`
- 增加小節數 選取一個小節右鍵
- 可以匯入MIDI，在打開的時候選擇類型為MIDI檔，然而簡譜大師原理為當打開雙通道MIDI優先為高音譜表為主，所以這樣會導致混亂
- 匯出到GuitarPro可以先導出mid在musesocre打開，在匯出為壓縮musicxml就可以完美從GuitarPro打開
- 輸入歌詞：音符文本到下一個音符按Enter
- 輸出midi檔沒有歌詞，音符會照原本的音高再加上填原本五線譜設定譜的調性
- 輸出midi用mid2jpw轉換還行，如果MuseScore輸出midi轉換就會出更大的錯
- 輸出midi要把原調設定好，最後轉出midi為正確調性歌曲
